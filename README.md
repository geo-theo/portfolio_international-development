# International Development Portfolio

This repository contains the static foundation for an international development project portfolio.

The homepage is intentionally blank for now. Shared design tokens, accessibility defaults, layout primitives, and the site favicon live in `dist/assets/` so new sections can be added incrementally without rebuilding the foundation.

## Structure

- `dist/index.html` — blank homepage entry point
- `dist/assets/styles.css` — shared visual system and reusable layout utilities
- `dist/assets/favicon.svg` — site-specific favicon
- `.openai/hosting.json` — static hosting configuration
